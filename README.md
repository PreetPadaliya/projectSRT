# Shree Radhe Thal

Frontend-only React + Vite website for Shree Radhe Thal, preserving the Gujarati and Kathiyawadi thali content, imagery, and theme.

## Development

Requires Node.js and npm.

```sh
git clone <this-repository-url>
cd <repository-name>
npm install
npm run dev
```

Build for production with `npm run build` and preview the build with `npm run preview`.
